🛍️ IndBuy — E-commerce Platform

IndBuy is an e-commerce platform designed to provide a simple and user-friendly online shopping experience.

🚀 Project Overview

This project focuses on building and improving an end-to-end e-commerce experience, including product browsing, category navigation, shopping cart functionality, product management, and administrative features.

✨ Key Features

- 🛍️ Product catalogue
- 📂 Category-based product navigation
- 🛒 Shopping cart
- 🔎 Product browsing
- 👨‍💼 Admin product management
- 📦 Order management
- 📱 Responsive user interface
- 🔐 User authentication
- ⚡ Modern web application architecture

🛠️ Technologies Used

- React
- TypeScript
- Tailwind CSS
- Node.js
- SQL
- Shopify
- Git & GitHub
- Figma
